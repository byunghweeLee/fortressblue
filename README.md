# FORTRESS BLUE · 포트리스 블루

2000년대 한국 턴제 포격 게임에서 영감을 받은 **독립 팬 프로젝트**입니다. 원작의 소스·그래픽·음원을 사용하지 않았으며 Canvas로 직접 렌더링합니다. 공식 포트리스 블루 제품과 관계가 없습니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. `dist/` 전체를 일반 정적 호스팅에 올려도 동작합니다. ES 모듈을 사용하므로 파일을 직접 더블클릭하지 말고 HTTP 서버로 열어 주세요. 외부 폰트가 로드되지 않아도 시스템 글꼴로 게임이 실행됩니다.

## 게임

- AI와의 2~4인 개인전, 또는 같은 기기에서 번갈아 조작하는 로컬 2~4인 개인전
- 스카이 아일랜드, 선셋 캐니언, 문라이트 베이스 3개 전장
- 매 턴 달라지는 바람, 중력, 발사 각도·파워에 따른 탄도
- 폭발 크레이터, 추락 탈락, 일반탄 및 탱크별 특수탄
- 45초 제한 시간, 턴 넘기기, 마지막 생존자 승리, 재대결
- 다음 턴 빙결 이동 봉쇄, 3턴 독 피해, 특수탄 2턴 재충전
- 선택형 합성 효과음, 반응형 화면, 키보드 및 터치 버튼

온라인 네트워크 대전과 계정/랭킹 서버는 포함하지 않습니다. 한 기기에서 AI 또는 다른 사람과 플레이합니다. 새로고침하면 진행 중인 전투는 초기화됩니다. 도움말·설정 창을 열거나 브라우저가 비활성화되면 실제 시간보다 게임 시간이 느리게 진행될 수 있습니다.

| 탱크 | HP | 이동 배율 | 특수탄 |
|---|---:|---:|---|
| 아이언 가드 | 1,200 | 0.8 | 헤비 버스터: 최대 340 피해, 넓은 폭발 |
| 레드 랩터 | 900 | 1.4 | 트리플 샷: 3발, 발당 최대 130 피해 |
| 프로스트 | 1,000 | 1.0 | 프로즌 코어: 최대 210 피해, 다음 턴 이동 봉쇄 |
| 베놈 | 950 | 1.1 | 베놈 클라우드: 최대 160 피해, 이후 3턴 × 55 피해 |
| 몰 머신 | 1,100 | 0.9 | 어스 브레이커: 최대 190 피해, 깊은 지형 파괴 |
| 볼트 | 950 | 1.15 | 썬더 스트라이크: 최대 180 피해, 주변 1대 추가 90 전격 |

일반탄 최대 피해는 240입니다. 폭심에서 멀어질수록 피해가 줄어듭니다. 모든 폭발과 상태 효과는 자신에게도 적용될 수 있습니다. 지형은 높이 배열로 구현되어 아래로 파이는 크레이터를 지원하며 동굴·지형 조각 분리는 지원하지 않습니다.

## 조작

- `← / →`: 이동 (턴마다 에너지 70, 경사가 심하거나 다른 탱크와 겹치는 위치로 이동 불가)
- `↑ / ↓`: 각도 (5~85도)
- 파워 슬라이더: 10~100%
- 포신 방향 버튼: 발사 방향 전환
- 일반탄 / 특수탄 버튼: 탄종 선택
- `Space` 또는 FIRE: 발사
- `?`: 조작법

키보드로 슬라이더·버튼에 초점을 옮긴 경우 해당 컨트롤의 기본 키보드 동작을 우선합니다. AI 모드에서는 PLAYER 01만 직접 조작합니다. 발사 전 점선은 초기 궤적만 표시합니다.

## 구조와 검증

- `dist/engine.js`: DOM 없는 전투 엔진·탄도·AI·상태 효과
- `dist/game.js`: Canvas 렌더링·입력·대전 설정·합성 효과음
- `dist/style.css`, `dist/index.html`: 반응형 게임 UI
- `server.mjs`: 외부 의존성 없는 로컬 정적 서버
- `tests/engine.test.js`: 탄도, 턴 전환, 특수탄, 상태 효과, 승리 및 AI 검증

```sh
npm run check
npm test
```

Canvas 렌더링 및 실제 기기별 브라우저 조작에 대한 자동 E2E 테스트는 포함하지 않습니다.
